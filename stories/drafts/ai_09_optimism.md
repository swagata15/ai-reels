# Story draft: "AI writes code now. Is it game over?"

~32 s · 11 lines · status: **script ready**, shots not built yet

## Recording script (one take, ~1 s pause between lines)
1. AI can write code now. So is it game over for tech jobs?
2. Look at the forecast.
3. The World Economic Forum expects 170 million new jobs by 2030...
4. and 92 million displaced.
5. That's a net gain of 78 million.
6. Meanwhile, AI agents can handle longer and longer tasks.
7. The length doubles about every seven months.
8. Which means new things to build: world models, multi-agent systems, AI evaluation.
9. These are forecasts, not guarantees.
10. Don't compete with AI. Learn to build with it.
11. What are you learning next?
